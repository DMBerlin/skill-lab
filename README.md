# Skill lab

This is my personal repository for agent skills I use and experiment with in
my day-to-day work.

The skills here evolve through real use. I refine them as I find rough edges,
collect feedback from live workflows, and learn which instructions produce
clearer and more reliable results.

Nothing here should be treated as finished or universal. Each skill reflects
what is working for me today and may change as the workflow around it improves.
